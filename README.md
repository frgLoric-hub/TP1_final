# TP1 PHP

BTS CIEL2IR - Developpement WEB

## Contenu

- **Exercice 1** : formulaire de date de naissance, calcul et affichage de l'age avec la fonction date()
- **Exercice 2** : verification d'un mot de passe, affichage de "Bonjour 007" ou d'un message d'erreur
- **Exercice 3** : saisie d'un nombre, affichage repete d'une phrase avec une boucle while

## Fichiers

- `index.php` : page d'accueil avec les trois formulaires
- `exos.php` : traitement des trois exercices
- `style.css` : mise en forme

## Utilisation

Placer le dossier dans `www/` de WAMP puis ouvrir `http://localhost/TP1_final/`
